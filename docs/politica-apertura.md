# Política de apertura de datos

La Política Nacional de Apertura de Datos (Decreto 118 de 2023) establece que toda la
información producida con recursos públicos es abierta por defecto, salvo las
excepciones de reserva previstas en la ley.

## Principios

- **Apertura por defecto**: la publicación es la regla, la reserva la excepción.
- **Oportunidad**: los datos se publican tan pronto como se consolidan.
- **Calidad**: los datos se acompañan de metadatos y documentación suficiente.
- **Accesibilidad**: formatos abiertos, legibles por máquina y sin restricciones técnicas.
- **Reutilización**: licencia única y permisiva para todos los conjuntos.

## Niveles de clasificación

| Nivel | Descripción | Publicación |
|---|---|---|
| Pública | Sin restricción | Inmediata |
| Pública con tratamiento | Requiere anonimización o agregación | Tras tratamiento |
| Clasificada | Afecta derechos de terceros | No se publica |
| Reservada | Seguridad nacional, defensa, relaciones exteriores | No se publica |
