# Conjuntos de datos

Cada subcarpeta corresponde a un conjunto de datos. Consulte `catalogo.csv` para el índice
completo y `../docs/diccionario-datos.md` para la descripción de cada columna.

Los archivos se nombran por período (`semana-NN.csv`, `AAAA-MM.csv`) o por lote de carga
(`lote-NNNN.csv`). Los lotes no se modifican una vez publicados; las correcciones se
publican como un lote nuevo con la columna `tipo_registro = corrección`.
